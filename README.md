# Modern Web Calculator

A sleek, responsive, and precision web calculator with scientific functions, memory, and calculation history.

## 🚀 Live Demo on GitHub Pages (Deployment Steps)

### Step 1: Create a GitHub Repository
1. Go to [github.com/new](https://github.com/new).
2. Enter repository name: `calculator` (or any name you like).
3. Set visibility to **Public**.
4. Click **Create repository**.

### Step 2: Upload Files
1. Click **uploading an existing file** on the repository page.
2. Drag and drop these 3 files:
   - `index.html`
   - `style.css`
   - `script.js`
3. Click **Commit changes**.

### Step 3: Turn on GitHub Pages
1. Go to **Settings** (tab at the top of your repo).
2. Click **Pages** in the left sidebar under *Code and automation*.
3. Under **Build and deployment** -> **Branch**:
   - Change `None` to `main` (or `master`).
   - Leave folder as `/ (root)`.
   - Click **Save**.
4. Refresh after 30 seconds — your live website URL will appear at the top:
   `https://<your-username>.github.io/<repo-name>/`

## ⚡ Instant Alternative: Netlify Drop (No GitHub Account Needed)
1. Open [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `web-calculator.zip` file or the `calculator` folder directly onto the page.
3. You will immediately get a live public `.netlify.app` URL with zero setup!
